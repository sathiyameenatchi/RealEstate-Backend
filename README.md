# RealNest

RealNest is a Full Stack Real Estate Listing Application.

## Technologies

- Spring Boot
- Spring Security
- JWT
- MongoDB
- Cloudinary

## Features

- User Registration
- Login with JWT
- Property Listing
- Property Search
- Add Property
- Edit Property
- Delete Property
- Admin Approval
- Admin Dashboard

## Run Backend

```bash
gradlew.bat bootRun
